# Roadmap

Build 42 is the primary target; Build 41 root metadata remains supported. The current launcher manages only the global `Zomboid/mods/default.txt` list. Save-list import and per-save/server configuration features recorded in older milestones were retired to keep the launcher focused on the global list. Those entries are retained as project history. Work has proceeded milestone by milestone under `docs/ARCHITECTURE.md`.

## Current product assessment and next checks

- **Implemented and fixture-verified:** read-only local/Workshop discovery, Build-aware metadata selection, staged Discover/Active Order editing, dependency proposals, Mod Packs, global-list preflight/apply/backup restore, and read-only diagnostics. The Windows installer and rolling updater have earlier hosted smoke evidence; the current 0.2.3 source has not been packaged or published.
- **Incomplete evidence:** Build 42 gameplay and full loader behavior remain unverified. A fixture or metadata warning cannot establish in-game compatibility. Manual Windows focus appearance and the current source's packaged behavior have not been checked.
- **Recent friction removed:** an equivalent list refresh could jump scroll position and switch Details to a stale Discover row. The 2026-10-24 UI fixture now protects each list's current row, selection, and scroll position while retaining the last inspected mod. Move Up/Down now shifts all selected Active Order rows one place instead of moving only the current row. Missing, duplicate, and removed selected Mod IDs now clear stale Description and external actions. Search-filtered rows keep their selection and details.
- **Next bounded priority:** Library & Diagnostics now retains a selected physical entry across equivalent scans and temporary search filtering and clears removed entries. Verify the accumulated source in a local packaged build before any push that would publish a rolling update. A 980×680 offscreen keyboard pass reached the enabled Apply and Launch actions from Details, so no keyboard redesign is planned without a reproduced defect.
- **Architecture audit:** the touched list state has one owner in `window_library.py`; a misplaced scan-failure handler was moved from the updater mixin to discovery. No duplicated parser, writer, worker, or UI component was found that warrants consolidation. No new core feature is justified before the state and packaging checks above.

## Remaining release gates

- Windows 11 x64 is the current verified target. Windows 10 Home/Pro is not a support target; Microsoft ended support on October 14, 2025. The v0.1.8 rolling workflow verified the update from the previous stable app on a hosted Windows 2022 runner. Manual another-PC checks were not run.
- The Qt/PySide6/WebEngine technical inventory, installer notices, and written source offer are prepared and recorded in `packaging/RELEASE_READY`; keep the offer available and re-review if bundled components or versions change. The original code is GPL-3.0-or-later.
- Releases are intentionally unsigned. Explain the expected SmartScreen warning in the README, and direct users to the official Releases page and the published checksum before running an installer.
- Workshop subscription/download actions and build-specific conflict guarantees remain out of scope until their behavior is independently verified. The release signing/provenance improvements remain separate from these feature changes.
